문제를 알려 주실 때

  • 게임 이름: 달빛 고물상 / Moonjunk Workshop
  • 테스트 버전: 알고 있는 경우 앱 버전, 기기 모델, iOS 또는 Android 버전
  • 발생한 일: 무엇을 하던 중 문제가 생겼는지, 기대한 결과와 실제 결과
  • 선택 첨부: 개인정보와 알림 내용을 가린 화면 캡처

비밀번호, 인증 코드, 로그인 토큰, 카드 정보, 신분증 또는 기기 전체 백업을 보내지 마세요. 처음에는 문제 설명만으로 충분합니다.

저장이나 로그인에 문제가 있나요?

테스트 앱을 바로 삭제하거나 다시 설치하지 말고 현재 상태를 보존해 주세요. 기기 전용 저장본은 계정의 서버 저장본과 다를 수 있습니다. 로그인 가능 여부는 테스트 버전과 서비스 설정에 따라 달라집니다.

계정 삭제를 원하시면 계정 삭제 안내를 먼저 확인해 주세요. 로그아웃이나 앱 삭제만으로 서버 계정 삭제가 완료되지는 않습니다.
