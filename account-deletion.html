계정 삭제 안내

달빛 고물상 / Moonjunk Workshop의 계정 삭제 방법을 안내합니다. 이 페이지 자체는 계정을 삭제하는 자동 처리 화면이 아닙니다.

마지막 업데이트: 2026년 9월 13일

현재는 개발 중입니다.일반 이용자용 계정 서비스는 아직 제공하지 않습니다. 아래 앱 내 절차는 계정 기능이 연결된 해당 테스트 버전에서만 적용됩니다. 계정이 없더라도 이메일로 관련 문의를 보낼 수 있습니다.

1. 앱에 접근할 수 있는 경우

  1. 달빛 고물상에서 계정과 백업을 엽니다.
  2. 삭제할 계정이 맞는지 확인하고, 연결된 Google 또는 Apple 로그인으로 다시 인증합니다.
  3. 미확인 백업이나 진행 요청이 있다면 앱 안내에 따라 먼저 확인합니다. 이 상태에서는 삭제 버튼을 사용할 수 없을 수 있습니다.
  4. 계정 삭제를 선택하고 삭제 안내를 읽은 뒤 확인합니다. 앱의 처리 결과를 확인해 주세요. 네트워크 오류나 비활성 버튼은 삭제 완료를 뜻하지 않습니다.

계정을 영구 삭제하면 해당 서버 여정과 클라우드 백업은 복원할 수 없습니다. 결정하기 전에 앱의 안내를 확인해 주세요.

2. 앱에 접근할 수 없거나 삭제가 되지 않는 경우

ialskdji@gmail.com으로 계정 삭제 요청 보내기

제목에 “Moonjunk 계정 삭제 요청”을 적고, 사용한 로그인 방식(Google 또는 Apple), 알고 있는 테스트 앱 버전, 앱에서 삭제할 수 없는 이유를 알려 주세요. 운영자가 요청을 확인한 뒤 필요한 계정 소유 확인 방법과 처리 범위를 안내합니다. 이메일 발신 주소만으로 계정 소유를 확정하거나 즉시 삭제하지 않습니다.

비밀번호, 인증 코드, 로그인 토큰, 카드 정보, 신분증은 보내지 마세요. 처음부터 원본 영수증이나 전체 저장 파일을 첨부할 필요도 없습니다. 요청을 보냈다는 사실만으로 삭제가 완료되지는 않으며, 확인 결과를 회신합니다.

3. 현재 구현에서 삭제되는 정보와 남을 수 있는 정보

계정 삭제 처리는 로그인 연결, 클라우드 게임 백업 및 보호된 서버 여정을 제거하고 세션의 접근을 중단하도록 구현되어 있습니다. 원래의 기기 전용 공방 저장본은 따로 보존합니다. 계정 삭제가 기기의 모든 저장 파일 삭제를 뜻하지는 않습니다.

현재 구현은 이미 사용된 구매 증명의 재사용을 막기 위한 최소 구매 연결 기록, 삭제 상태를 포함한 내부 계정 기록과 무효화된 세션 메타데이터를 남길 수 있습니다. Apple 인증 철회가 아직 처리되지 않았다면 필요한 암호화 자료와 재시도 기록이 남을 수 있습니다. 서버 운영 백업의 삭제 반영 시점과 최종 보관 기간은 아직 확정되지 않았습니다.

이것은 현재 개발 상태에 대한 설명입니다. 앱을 배포하기 전에 남기는 정보의 정확한 범위·목적·보관 기간과 백업 삭제 절차를 확정해 공개해야 합니다. 현재 테스트 자료에 대한 요청은 운영자가 실제 보유 정보와 처리 결과를 확인해 안내합니다.

4. 계정 삭제와 다른 작업

  • 로그아웃: 계정이나 클라우드 백업을 삭제하지 않습니다.
  • 앱 삭제: 서버 계정 삭제 요청을 대신하지 않습니다. 기기 전용 저장본을 잃을 수 있습니다.
  • 구매 환불: 계정 삭제로 자동 처리되지 않습니다.
  • 웹사이트 문의 기록: 이메일 문의 자료의 삭제는 별도로 요청할 수 있습니다. 개인정보 안내를 확인해 주세요.
