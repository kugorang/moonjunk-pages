개인정보 안내

이 안내는 현재의 출시 전 소개 웹사이트와 이메일 문의에 적용됩니다. 아직 일반 이용자에게 제공하지 않는 게임 앱의 최종 개인정보처리방침을 대신하지 않습니다.

마지막 업데이트: 2026년 9월 13일

웹사이트와 개발 중인 앱은 구분됩니다.이 사이트에서는 게임에 로그인하거나 계정을 만들거나 광고를 시청하거나 결제할 수 없습니다. 웹사이트 방문만으로 게임 저장본이나 로그인 정보를 받지 않습니다.

1. 운영자와 연락처

달빛 고물상 / Moonjunk Workshop의 운영자는 김현우 (Kim Hyeonwoo)입니다. 개인정보 관련 열람·정정·삭제 요청과 질문은 ialskdji@gmail.com으로 보내 주세요.

2. 웹사이트를 방문할 때

이 사이트는 GitHub Pages에서 제공하는 정적 페이지입니다. 운영자가 추가한 방문 분석, 광고 추적, 쿠키, 브라우저 저장소, 문의 양식 및 외부 폰트가 없습니다. 언어 선택은 다른 언어 페이지로 이동하는 링크이며 별도로 저장하지 않습니다.

호스팅 제공자인 GitHub는 보안 목적으로 방문자의 IP 주소를 기록하고 보관한다고 안내합니다. GitHub 로그인 여부와 관계없이 적용됩니다. 자세한 내용은 GitHub Pages 데이터 수집 안내와 GitHub 개인정보처리방침을 확인해 주세요. GitHub가 보관하는 로그를 운영자가 이 사이트에서 직접 삭제할 수는 없습니다.

3. 이메일로 문의할 때

이메일을 보내면 운영자는 발신 주소, 메시지, 직접 첨부한 자료를 받습니다. 이 정보는 문의 확인, 회신 및 관련 문제 해결을 위해 사용합니다. 이메일은 Gmail을 통해 수신하며 이메일 제공자의 처리도 적용됩니다. Google 개인정보처리방침을 확인할 수 있습니다.

문의 내용은 공개 게시하지 않습니다. 비밀번호, 인증 코드, 로그인 토큰, 결제 수단 정보나 불필요한 개인정보는 보내지 마세요. 문의 이메일의 삭제 또는 정정은 같은 연락처로 요청할 수 있습니다. 현재 일괄 적용되는 확정 보관 기간은 없으며, 개별 요청에서 삭제 범위와 필요한 보관 여부를 확인해 안내합니다.

4. 개발 중인 게임의 데이터 처리 방향

아래는 현재 구현의 설명이며, 실제 운영 서비스가 제공되고 있다는 뜻은 아닙니다. 테스트 버전마다 활성화된 기능은 다를 수 있습니다.

  • 기기 저장: 게임 진행, 수선공 이름, 이야기 확인 상태와 설정 등을 기기에 보관하는 경로가 있습니다.
  • 계정과 백업: Google·Apple의 검증된 로그인 식별자, 내부 계정 ID, 세션 정보, 선택한 백업과 서버 여정을 다루는 기능을 개발 중입니다. 로그인 이메일만으로 계정을 식별하거나 사용자 비밀번호를 직접 받는 방식이 아닙니다.
  • 구매와 광고 보상: 스토어 구매 증명과 계정 연결, 광고 보상 검증 기록을 처리하는 구현이 있습니다. 실제 서비스 활성화 및 최종 제공자 구성을 확정하기 전 단계입니다. 이 웹사이트에는 구매·광고 기능이 없습니다.
  • 계정 삭제: 서버 여정과 백업을 삭제하는 경로와 별도로, 최소 구매 연결 기록·계정 및 세션 메타데이터·미완료 Apple 인증 철회 자료 등이 남을 수 있습니다. 삭제 안내에서 현재 구현의 범위를 설명합니다.

앱을 배포하기 전에 실제 수집 항목, 목적, 제공자와 이전·보관 위치, 보관 기간, 삭제 범위, 광고·연령·동의 처리 및 이용자 권리를 반영한 앱용 정책을 확정하고 공개해야 합니다. 이 출시 전 안내를 완성된 앱 정책이나 모든 데이터의 즉시 삭제 약속으로 해석하지 말아 주세요.

5. 안내 변경

웹사이트 또는 서비스의 데이터 처리 범위가 바뀌면 이 페이지와 업데이트 날짜를 수정합니다. 이 페이지에 표시된 날짜가 현재 안내의 기준일입니다.
